# ARCHIVE — superseded specifications

**Superseded. Reference only. Do NOT build from this.**

These documents specify `scaffold`, a coupled population–infrastructure simulator for
treatment-dependent viability. That project was redirected to `stewardsim` on 2026-08-12.
See `DECISIONS.md` ADR-001 for the reasoning and a full carried/replaced/retired inventory.

Retained because the reasoning is useful — particularly the derivation showing that relaxed
selection on recessive disease alleles freezes rather than inflates allele frequency, and
the scaffold-failure formalism, which reappears in `stewardsim` with consumption as the
degradation mechanism.

Nothing here is a build target. If a design question appears answered here and not in the
active `GOAL.md`, the answer is that the active spec governs — raise it rather than
importing from this directory.
